# Выпускная квалификационная работа

Тема: **«Разработка системы анализа научных публикаций для обогащения материалов киберразведки с использованием больших языковых моделей»**.

> [!NOTE]
> **Итоговый документ — [Глава1.docx](artifacts/Глава1.docx).** Текст первой главы ВКР с приложением А «Основания сравнительных оценок». Аналитический отчёт содержит исходные данные и расчёты, на которых основаны разделы 1.3–1.4.

Сайт с актуальными материалами: <https://grigorytishkov.github.io/Threat-Intelligence-VKR/>.

В репозитории размещены промежуточные результаты работы по ВКР, артефакты и тезисы. На текущем этапе выполнен анализ предметной области и существующих решений, обоснованы требования к системе и подготовлены материалы для представления результатов.

## I. Артефакты

### 1. Аналитический отчёт

Файл: [analytical_report.qmd](artifacts/analytical_report.qmd).

Сравнение охватывает два направления:

| Направление | Решений | Критериев | Оценок |
| --- | ---: | ---: | ---: |
| Источники и платформы Threat Intelligence | 10 | 19 | 190 |
| Инструменты поиска и обработки научных публикаций | 11 | 10 | 110 |
| **Всего** | **21** | **29** | **300** |

В отчёте представлены четыре основные сравнительные таблицы:

| Таблица | Что сравнивается |
| --- | --- |
| Состав сведений TI-источников | Типы индикаторов, CVE, вредоносное ПО, группировки и связь с MITRE ATT&CK / TTP |
| Контекст записи и передача сведений | Временные характеристики, происхождение, оценка опасности или достоверности, выдача STIX и TAXII |
| Обнаружение и организация литературы | Поиск статей, мониторинг новых работ, граф цитирований и тематическая организация |
| Извлечение содержания и проверка результата | Полный текст, извлечение по схеме, собственные поля, подтверждающие фрагменты, экспорт извлечений и предметная схема угроз и защиты |

В сравнении используются три значения:

- **«Да»** — возможность документирована для рассматриваемого объекта.
- **«Нет»** — в использованном источнике явно описано ограничение.
- **«Не установлено»** — сведений недостаточно для определённого вывода; это значение не означает отсутствия возможности.

CVE, вредоносное ПО, группировки и тактики, техники и процедуры атакующих рассматриваются отдельно от типов индикаторов компрометации. STIX как формат представления и TAXII как механизм обмена также оцениваются раздельно.

Результаты относятся к выбранным продуктам, интерфейсам, режимам и исследовательским реализациям. Возможности платформы, конкретного потока, отдельной записи и выгрузки разграничиваются. Наличие функции по документации не характеризует качество её выполнения. Уровень документального основания каждой оценки учитывается отдельно от значения «Да», «Нет» или «Не установлено».

## II. Воспроизводимость и запуск

Сайт собирается из исходников автоматически. При каждом push в ветку `main` GitHub Actions заново выполняет код R в отчётах, рендерит их в Quarto и публикует результат на GitHub Pages (`.github/workflows/publish.yml`). Если данные или код отчёта перестают сходиться, встроенные проверки останавливают сборку, и сайт не обновляется.

Локально: в RStudio откройте нужный файл `.qmd` и нажмите **Render**; результат появится в папке `_site/`. Из терминала в корне репозитория:

```bash
quarto render                                   # весь сайт
quarto render artifacts/analytical_report.qmd   # только отчёт
quarto preview                                  # просмотр сайта с автообновлением
```
