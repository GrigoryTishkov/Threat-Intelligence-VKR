# Выпусная квалификационная работа на тему: "Разработка системы анализа научных публикаций для обогащения материалов киберразведки с использованием больших языковых моделей"

В репозитории размещены промежкточные результаты работы по ВКР, артефакты и тезисы.

## I. Артефакты

## 1. Сравнительная таблица Threat Intelligence Feeds

Файл: [Threat_intelligence_feeds.xlsx](artifacts%2FThreat_intelligence_feeds.xlsx).

В книге семь листов:

| Лист | Назначение |
| --- | --- |
| `Матрица 10 решений` | Подтверждённые типы IoC, отдельные виды контекста и флаги выдачи через STIX/TAXII |
| `Правила чтения` | Значение флагов и разграничение возможностей продукта, потока и записи |
| `Источники` | 38 официальных источников с кодами, ссылками, разделами документации, датами проверки и пределами подтверждения |
| `Обзор рынка` | Десять решений по пяти группам признаков, включая описания угроз и возможности аналитика |

| `STIX и TAXII` | Поддержка выдачи собственных данных, версии стандартов, направление обмена и ограничения подтверждения |
| `Потоки и поля` | 23 описания конкретных потоков, выгрузок, операций API, материалов портала и аналитических отчётов: объекты, основные значения, контекст и ограничения |

В матрице **«Да»** означает подтверждение в использованном источнике; **«Нет»** — явное ограничение исследуемого набора данных; **«Не установлено»** — недостаток открытых сведений, а не отсутствие возможности. Цвета: зелёный, красный и жёлтый соответственно; остальные ячейки имеют белый фон. CVE, вредоносное ПО (ВПО), группировки и тактики, техники и процедуры атакующих (TTP/ATT&CK) не считаются типами IoC; они проверяются отдельно.

### Четыре категории решений

| Категория | Рассмотренные решения | Особенность сравнения |
| --- | --- | --- |
| Коммерческие TI-фиды | Kaspersky Threat Data Feeds; F6 Threat Intelligence Feeds; PT Threat Intelligence Feeds | Сопоставлять состав **конкретного потока**, а не только рекламное описание поставщика |
| Комплексные TI-платформы | BI.ZONE Threat Intelligence; Recorded Future; VirusTotal | Платформа шире, чем доступный через неё отдельный фид или набор данных |
| Платформа обмена TI | AlienVault OTX | Пользователи публикуют тематические записи `Pulses` с индикаторами и ссылками |
| Специализированные открытые источники | ThreatFox; URLhaus Plain-Text URL List; MalwareBazaar | Узкие наборы по ВПО, URL или файлам; не прямые функциональные аналоги платформ |

### Пять групп признаков для анализа рынка

1. **Назначение и модель предоставления:** тип продукта, сценарий использования, свободный доступ или лицензия.
2. **Источники и формирование данных:** сенсоры, расследования, эксперты, сообщество; отбор и проверка.
3. **Состав и контекст:** IoC, CVE, ВПО, группировки, TTP; описания атак и кампаний, цели и мотивация, отрасли и регионы; репутация, время, связи, источник и основания утверждения.
4. **Доступ и интеграция:** API, форматы, обновление, история, ограничения и стоимость там, где они подтверждены.
5. **Работа аналитика:** поиск, фильтрация, проверка происхождения, исследование связей, применение результатов.

## 2. Сравнение средств поиска и анализа научных публикаций

В таблице рассмотрены одиннадцать решений для поиска и обработки научных публикаций: девять научных сервисов и платформ и два исследовательских решения по информационной безопасности. Сравнение охватывает получение статей, обработку содержания, сопоставление результатов, проверяемость и выдачу данных. Сведения основаны на официальной документации, справке разработчиков и авторских научных публикациях; экспериментальная проверка качества работы инструментов не проводилась.


Файл: [`artifacts/scientific_publications_tools_comparison.xlsx`](artifacts/scientific_publications_tools_comparison.xlsx).

В книге шесть листов:

| **Лист** | **Назначение** |
| --- | --- |
| `Матрица 11 решений` | Подтверждённые возможности одиннадцати решений по 26 признакам: поиск, обработка содержания, сопоставление, проверяемость и выдача результатов |
| `Правила чтения` | Значение флагов, границы сравнения и различия между видами документов, графов, подтверждений и экспорта |
| `Источники` | 43 первичных источника с кодами, ссылками, разделами, датами проверки и пределами подтверждения |
| `Обзор рынка` | Назначение решений, входные материалы, результаты, способы проверки, корпус и покрытие ИБ, возможности применения и ограничения |
| `Категории и критерии` | Определения 26 признаков, объединённых в пять групп, и условия их подтверждения |
| `TI-отчёты` | Отдельное описание ThreatKG и CTINexus: обработка материалов киберразведки, функции, результаты и границы сравнения с научными источниками |


### Пять категорий решений

| **Категория** | **Рассмотренные решения** | **Особенность сравнения** |
| --- | --- | --- |
| Коммерческие научные сервисы | Elicit; SciSpace; Scite; Consensus; Iris.ai RSpace | Сопоставляются конкретные режимы поиска, ответов, извлечения и экспорта; подтверждение одной операции не переносится автоматически на другие |
| Научный поисковый сервис и инфраструктура | Semantic Scholar | Поиск, библиографические данные и API рассматриваются отдельно от функций чтения и ответов, доступных для части корпуса |
| Коммерческие сервисы поиска литературы | ResearchRabbit; Litmaps | Поиск связанных работ и карты цитирования не означают извлечение результатов исследования из полного текста |
| Открытый научный сервис | ORKG ASK | Возможности поиска и структурированного представления исследований учитываются по описанию версии в авторской статье 2024 года |
| Исследовательские решения по ИБ | Киберграф на HSNMFk-SPLIT; AI-security Knowledge Graph | Учитываются состав экспериментального корпуса, область исследования и статус реализации; описание метода не подтверждает наличие готового коммерческого сервиса |

ResearchRabbit и Litmaps учитываются как два продукта; оба сайта указывают Litmap Limited, поэтому их включение не означает двух независимых поставщиков. ThreatKG и CTINexus описаны на отдельном листе и не входят в основную матрицу одиннадцати решений: подтверждённая обработка TI-отчётов не устанавливает использование научных исследований в качестве входного корпуса.

### Пять групп признаков для анализа рынка

1. **Поиск и поступление:** поиск научных статей, мониторинг новых публикаций, загрузка PDF для обработки.
2. **Содержание публикаций:** работа с полным текстом, автоматическое резюме, извлечение по схеме и пользовательские поля; условия и ограничения исследования, данные и результаты, тип подтверждения выводов.
3. **Сопоставление и изучение:** сравнение работ по общим полям, ответы на вопросы, библиографический граф, тематическая карта, предметный граф ИБ и сохранение несовпадающих результатов со связью с источниками.
4. **Проверяемость результатов:** связь с исходной статьёй, подтверждающие фрагменты, характер цитирования, подтверждения к отдельным полям и сохранение ручных исправлений извлечений.
5. **Предметная модель и выдача:** встроенная схема угроз и защиты, экспорт библиографии, экспорт извлечённых сведений, документированный API и сопоставление с CVE или MITRE ATT&CK.
